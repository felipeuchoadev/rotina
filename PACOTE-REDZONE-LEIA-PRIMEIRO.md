# PACOTE COMPLETO DE CONTINUIDADE — REDZONE

Este pacote foi preparado para continuar o REDZONE em outra IA, computador ou
equipe sem perder o contexto técnico e funcional.

## Comece aqui

1. Abra `docs/12-PACOTE-DE-TRANSICAO.md`.
2. Leia o aviso no topo de `docs/10-STATUS-E-ROADMAP.md`.
3. Confira `VERSAO-EXPORTADA.txt` e `MANIFESTO-SHA256.txt`.
4. Use `redzone-repository.bundle` para restaurar o histórico Git ou abra
   `snapshot/` para consultar imediatamente o código.
5. Consulte `docs/14-AUDITORIA-26-CAPTURAS.md` para a revisão funcional mais recente.

## Aviso de segurança

O ZIP não contém chave SSH privada, `.env`, senha do banco, tokens, banco real,
uploads privados nem senhas de usuários. O mapa seguro desses acessos está em
`docs/13-ACESSOS-E-SEGREDOS-NAO-INCLUIDOS.md`.

Não envie credenciais reais para outra IA. Entregue acessos por convite e cofre
de senhas, com permissões mínimas e possibilidade de revogação.

## Regra principal

Não refaça a aplicação antiga. A fonte de verdade é o código atual, o endereço
`https://redsystems.ddns.net/rotina/` e o topo do roadmap. Preserve banco,
contas, mídias e alterações dos usuários.
